# Animated Portfolio

Starter for a premium animated frontend portfolio using Next.js, GSAP, Framer Motion and shadcn-style UI components.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Current milestone

- Dark cinematic design
- Animated fixed navbar
- GSAP hero entrance timeline
- Floating/orbiting hero effects
- Framer Motion mobile menu
- Responsive layout
- shadcn-style Button + `cn` utility
- Placeholder portrait area ready for the real photo
